## 风险与增量检查

Reviewer 新增的独立本地证据：

- 只读解包两份最终 IPK，哈希和大小与设备记录一致；检查父目录项、root uid/gid、路径无绝对/上级目录、无软/硬链接、init 可执行、包不含运行 config.json。后端 10 个及界面 3 个载荷文件逐字节匹配当前源码。

- 检查 daemon 只新增 get/save/action 的 ubus_rpc_session policy；核心校验、密码剔除、冷却和取消调用链未改变。检查 rpc_acl.uc 的 HTTP 层拒绝断言，确认它能区分网关权限拒绝与业务层 invalid_config/invalid_action。

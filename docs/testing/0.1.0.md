- 独立首审 CL-R01–08 已关闭，核心有条件通过，见 [审查](../reviews/cl-01.md)。复核指出大小测试单字段提前越界，已修正为每个 URL 恰好 1024 字节并重新通过：合法字段组成的总尺寸超限被拒绝。

# CL-01：核心配置、后台与 LuCI

目标：实现精简 CampusLink，不增加额外用户体系、云服务或配置加密。
依据：REQ-002 / AC-008–010、用户完整开发授权。
depends_on：CL-FRAMEWORK-01；不依赖真实校园账号。
范围：账号、已有 WAN/学校/提供商、原生 LuCI、定时检查/重新登录、限频、服务启停。非目标：创建 WAN、路由、防火墙、固件或代理。
设计：单份 root 0600 JSON，读取剔除密码，省略保留；atomic rename 和 generation。最多 64 账号/32 线路、256 KiB、并发 2。worker 进程组包含 curl，取消时一并结束。
风险 R2：凭据及出口绑定可能导致泄露/错误账号请求，已做行为测试与独立审查。
实施：完成。验证：目标 ucode、mock、真实假 HTTP 取消/自动恢复、原生 LuCI 配置及动作通过，见 [证据](../testing/0.1.0.md)。
审查：CL-R01–08 已关闭，核心及最终设备交付复核通过，见 [核心报告](../reviews/cl-01.md)和[最终报告](../reviews/cl-03.md)。发布：已在授权测试设备安装，未外部发布。

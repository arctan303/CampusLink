# CampusLink 界面设计

适用：CL-UI-01，用户已授权按界面分析开始优化。目标用户为已能进入 LuCI 的路由器管理员；主要任务是查看线路状态、给 WAN 配置登录和复用账号。采用原生 LuCI 控件与主题。

## 方向与约束

“简洁”落实为功能标签页、紧凑列表、局部编辑、默认参数封装和高级设置折叠。CL-UI-02 按用户决定扩为五个标签：总览、登录配置、账号、插件设置、日志。放弃长页平铺，因为跨区域配置和滚动增加操作成本；放弃额外仪表盘、图表和独立皮肤，因为状态表与表单已能完成任务。

颜色、字体、圆角遵循当前 LuCI 主题；仅为状态使用浅背景标签并同时显示文字，不以颜色作为唯一信息。内容采用单层标题、列表和操作条；间距以 8/16px 为单位。表格适配窄屏横向滚动，编辑弹窗内表单保持纵向布局。按钮和输入沿用 LuCI 尺寸，标签关联输入 ID，键盘可切换标签和操作控件，不增加动效。

## 交互规则与验收

| 意图 | 决策与参数 | 理由与代价 | 检查点 |
| --- | --- | --- | --- |
| 先看是否在线 | 总览只显示 WAN、绑定账号、方式、状态、自动登录和操作；正常状态无常驻限制说明或秒级倒计时 | 详细原因移至错误行或日志 | 四路在线时无需滚动到配置表单；无用户点名文案 |
| 配置一次完成 | 登录配置列表的新增/编辑弹窗可选择已有账号或内联新增；弹窗保存立即提交完整原子配置 | 后端整体保存 API 保留，前端只修改本次对象 | 新账号与 WAN 一次保存；取消不创建账号；重复保存受限；冲突不覆盖 |
| 校园公共配置只填一次 | 插件设置统一选择认证系统/学校/服务器及检查周期，高级覆盖包含 URL/探测/重试；WAN 表单只有接口、账号、终端、启用/自动登录及可选名称 | 公共改动影响所有 WAN，保存区域标明作用范围；切换系统/学校移除旧地址，异构旧配置先保持 | WAN 中没有重复的提供商/学校/服务器/周期；公共保存一次生效，取消保留 |
| 维护账号快速 | 账号列表显示别名、用户名、引用线路与编辑/删除；密码只在编辑弹窗输入 | 保留已有不回读密码契约 | 标题使用别名；留空保留；引用账号不能删除 |
| 保留特殊参数 | 插件设置的高级区域显示公共自定义 URL/探测/重试，线路高级区域仅名称及声明为线路级的少见字段；不支持的退出参数不展示 | 旧非标准覆盖不能静默丢失，存在时展开；异构配置先由管理员选择公共值 | 改服务器联动默认端点；明确的特殊覆盖保留；没有隐藏必填项 |
| 异常可处理 | 表单错误在弹窗内显示；提交中禁用保存；后台错误显示简短原因；日志单独查看 | 日志提供必要诊断而非长期说明 | 失败不关闭弹窗或丢草稿；轮询不覆盖正在编辑的值 |

已有线路的启用状态不因界面简化改变。新线路维持默认禁用、自动登录关闭，启用开关在基础表单明确显示；这是保留现有行为的常规字段。新增时默认选择尚未配置的 WAN，账号仍可多路复用。

# CampusLink 界面设计

适用：CL-UI-01，用户已授权按界面分析开始优化。目标用户为已能进入 LuCI 的路由器管理员；主要任务是查看线路状态、给 WAN 配置登录和复用账号。采用原生 LuCI 控件与主题。

## 方向与约束

“简洁”落实为功能标签页、紧凑列表、局部编辑、默认参数封装和高级设置折叠。CL-UI-02 按用户决定扩为五个标签：总览、登录配置、账号、插件设置、日志。放弃长页平铺，因为跨区域配置和滚动增加操作成本；放弃额外仪表盘、图表和独立皮肤，因为状态表与表单已能完成任务。

CL-MWAN-06 将“mwan3 联动”作为第六个独立标签，与认证公共设置分开。总开关在前，映射表每行依次为启用、CampusLink 接口、mwan3 接口、关联成员、实际状态、删除；提供新增映射和独立保存/恢复。来源与目标使用已有对象下拉框，不靠手填名称。未安装/服务不兼容时展示状态，其他标签可继续使用。放弃把联动字段塞进每路认证弹窗，因为映射与成员资格需要集中核对；也不复制 mwan3 的权重/策略编辑器。

映射编辑草稿跨标签保留，状态轮询不改输入，过期版本不能覆盖已保存配置；保存失败保留草稿。行开关与实际状态分列，成员名称只读随目标选择更新。选中的对象已删除时保留其名称并标明失效，允许停用/删除后保存恢复。缺少原生跟踪准备或出口不一致在对应行说明。停用的影响在保存区提示：停止控制并保留成员状态，恢复原生探测需在 mwan3 配置。检查点为超过四行、小屏横向滚动、下拉标签关联、键盘可操作，以及取消/失败/冲突后的草稿。

颜色、字体、圆角遵循当前 LuCI 主题；仅为状态使用浅背景标签并同时显示文字，不以颜色作为唯一信息。内容采用单层标题、列表和操作条；间距以 8/16px 为单位。表格适配窄屏横向滚动，编辑弹窗内表单保持纵向布局。按钮和输入沿用 LuCI 尺寸，标签关联输入 ID，键盘可切换标签和操作控件，不增加动效。

## 交互规则与验收

| 意图 | 决策与参数 | 理由与代价 | 检查点 |
| --- | --- | --- | --- |
| 先看是否在线 | 总览只显示 WAN、绑定账号、方式、状态、自动登录和操作；正常状态无常驻限制说明或秒级倒计时 | 详细原因移至错误行或日志 | 四路在线时无需滚动到配置表单；无用户点名文案 |
| 配置一次完成 | 登录配置列表的新增/编辑弹窗可选择已有账号或内联新增；弹窗保存立即提交完整原子配置 | 后端整体保存 API 保留，前端只修改本次对象 | 新账号与 WAN 一次保存；取消不创建账号；重复保存受限；冲突不覆盖 |
| 校园公共配置只填一次 | 插件设置统一选择登录系统/服务器及检查周期，高级覆盖包含 URL/探测/重试；CL-SCHED-01 待实现的计划停网策略普通区仅放开关/时段/摘要，高级放次数和用尽后的策略。WAN 表单只有接口、账号、终端、启用/自动登录及可选名称。CL-UI-03 移除学校入口，旧继承值在保存时显式保留 | 公共改动影响所有 WAN，保存区域标明作用范围；切换系统移除旧地址，异构旧配置先保持 | 没有学校选择及恢复预设操作；旧配置不丢服务器/特殊 URL/终端；公共保存一次生效，取消保留；停网策略条件显示与摘要一致 |
| 维护账号快速 | 账号列表显示别名、用户名、引用线路与编辑/删除；密码只在编辑弹窗输入 | 保留已有不回读密码契约 | 标题使用别名；留空保留；引用账号不能删除 |
| 保留特殊参数 | 插件设置的高级区域显示公共自定义 URL/探测/重试，线路高级区域仅名称及声明为线路级的少见字段；不支持的退出参数不展示 | 旧非标准覆盖不能静默丢失，存在时展开；异构配置先由管理员选择公共值 | 改服务器联动默认端点；明确的特殊覆盖保留；没有隐藏必填项 |
| 异常可处理 | 表单错误在弹窗内显示；提交中禁用保存；后台错误显示简短原因；日志单独查看 | 日志提供必要诊断而非长期说明 | 失败不关闭弹窗或丢草稿；轮询不覆盖正在编辑的值 |

已有线路的启用状态不因界面简化改变。新线路维持默认禁用、自动登录关闭，启用开关在基础表单明确显示；这是保留现有行为的常规字段。新增时默认选择尚未配置的 WAN，账号仍可多路复用。

CL-NET-01 在总览复用现有表格增加“公网 IPv4”列，原 WAN 次行明确标为“接口 IP”；列内显示结果、查询时间/失败/过期说明及查询/刷新按钮。不加设置页，不以查询失败覆盖已联网状态；共用已有按钮、次级文案和横向滚动规则。

[CL-SCHED-01](tasks/scheduled-outage-retry.md) / REQ-008（待实现）：用户要求控制设置数量，沿用“插件设置”的普通/高级折叠结构。普通区提供默认关闭的“计划停网重试策略”开关，启用后显示开始/结束时间和按当前草稿生成的简短行为摘要；高级区提供每路次数（默认 3）、额度用尽后的策略（默认等待时段结束）及定期试登录间隔（默认 30 分钟，仅对应策略显示）。启用时段不得默认套用本校规则，不增加学校对象、独立设置页或全部内部参数。

严格策略摘要应说明“每个时段每路最多自动登录 N 次，用尽后等待时段结束；期间保留低频联网检查”；定期策略明确“初始 N 次后，每隔 X 分钟再试登录”，避免暗示总次数仍受 N 限制。用尽额度的行状态解释等待原因及下次允许时间，不直接展示机器码或把门户可达写成恢复。低频检查取得明确联网证据时更新在线状态，额度保持。设计代价是普通区隐藏调优参数，由摘要解释当前行为；验证折叠/条件显示、时段输入标签、键盘和窄屏布局、错误定位、草稿保留及状态轮询不改输入，不以颜色作为唯一提示。

D-20261014-20 / [CL-DIAG-01](tasks/doctor-report.md)（待实现）确认“一键诊断＋复制脱敏报告”为功能范围。复用现有 LuCI 控件显示分层结果、原因/建议与复制入口；超时/未执行/部分失败和复制失败均有文字说明，等待时防重复提交。分享内容由允许字段构建，页面不渲染原始门户 HTML。当前不推进手机卡片、额外灯号或布局重做；这些优化后置，必要诊断交互与已有可访问性要求保留。

D-20261014-22 / REQ-011（待实现）：总览增加一个“全部检查”入口，不增加“全部登录”。用简短说明表达“沿用各线路自动登录设置”，逐路展示进行中、跳过原因和最终结果；批次运行中防重复提交，状态轮询不制造新任务。复用现有按钮/状态控件，避免全局成功提示掩盖某路失败；与只读“一键诊断”名称和行为区分，布局优化仍后置。

D-20261014-23 / [CL-MWAN-07](tasks/mwan3-unknown-expiry.md)（待实现）：在既有联动状态文本中解释“长期无法确认，暂停分流”和“所有线路暂时无法确认，保留当前分流”，配合最后成功证据时间，避免把保留资格显示成刚刚验证健康。恢复依赖新证据，提示按有效状态变化记录；不新增灯号仪表盘或调参面板。账号保护/计划停网等待原因单独解释，不把停止自动认证显示为所有 WAN 已断网。

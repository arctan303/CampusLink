# CL-UI-02：插件公共设置

来源：2026-10-08 用户要求增加插件设置，将 Dr.COM 等认证系统和公共参数移出 WAN 配置；随后确认所有 WAN 共用检查周期。关联 REQ-002、AC-013，替代 CL-UI-01 中每路选择提供商/学校及检查周期的界面规则。

目标：同一个校园只配置一套认证系统、学校及服务器；每路只绑定账号、终端方式和线路开关。新增“插件设置”标签，基础显示认证系统、学校、服务器及检查周期，高级显示特殊 URL、探测地址和重试参数。账号仍独立复用，新增线路内可新增账号。

范围：配置 schema 2、统一设置、旧配置兼容迁移、LuCI、测试、IPK 和原设备更新。非目标：新认证协议、已未支持的本校退出、网络/防火墙/代理、额外凭据保护或用户系统。依赖当前 0.2.0、提供商声明、已授权路由器及回退备份。

风险 R2：公共认证目标变更影响全部 WAN，迁移或合并错误可能向错误目标发送凭据或改变账号绑定。需要有效端点一致、字段作用域、密码及原账号/出口保留验证和 fresh reviewer；不因页面数评级。

预期：schema 2 settings 为认证公共参数和调度参数唯一来源；connection 只存线路信息和提供商声明的 per-line 参数。同类旧配置自动在内存迁移，首次保存再写 schema 2；异构旧配置维持原调度、不自动统一，提示先在插件设置选择公共配置。未知 schema 停止，不静默回退。切换系统清除旧系统参数，仅保留新系统可兼容的线路参数，账号/接口/启用状态不变；改变学校清除旧学校参数并采用新预设。旧包回退须恢复升级前配置。

验收：五标签/同页公共保存；WAN 表单无提供商/学校/服务器/检查和重试字段；公共改动原子应用全线；配置失败/取消/过期版本不改变持久化；账号、密码、终端和接口保留；旧同类配置端点/周期不变、异构不误迁移；字段作用域由后台强制；原设备四路在线和管理路径/网络配置保持。

状态：实施、针对性验证、独立审查及已授权设备发布完成。0.3.0 两包已更新；旧配置先在内存迁移，页面首次公共保存写 schema 2，generation 9→10；共用周期 120→60 后 WAN 原样保存至 generation 12。服务重启后四路在线；原两账号及密码、四个绑定/终端/开关/有效端点/周期、网络与防火墙校验保持。五标签、全局草稿/恢复、系统切换表单、折叠错误定位、WAN 保存/取消及 390px 小屏通过。

验证见 [0.3.0](../testing/0.3.0.md)，fresh reviewer 首审及一次聚焦复核见 [报告](../reviews/plugin-settings.md)，唯一示例作用域问题已关闭。最终包及源码经私有注入和确定性构建审计；实际安装源码哈希与最终工作区一致。本轮未重新真实退出/踢出校园会话，沿用原协议与出口验证；旧包/schema 回退流程文档化，未在正式 schema 2 上再次执行降级。

恢复基线 `.local/settings-baseline` 为 0.2.0 本轮纯源码副本，旧 0.2.0 IPK 保留在 dist；设备 `/tmp/campuslink-settings-backup` 为 root 私有原配置和旧包（重启路由器会清空 /tmp）。本轮临时 mock 服务、测试目录与准确匹配的临时 SSH 公钥已清理，正式服务仍运行。本轮不修改其他网络任务，未推送或发布 GitHub。

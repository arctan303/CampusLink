# CL-MWAN-07：未知资格有条件过期

目标与来源：2026-10-14 用户确认“单路异常先隔离，全部不明先保留”的默认方案，依据 D-20261014-23、[REQ-012 / AC-035–037](../Product-Spec.md)及[设计规范](../Design-Brief.md)。承接现有 MWAN-05 / CL-MWAN-06 的长期未知无年龄上限边界，保留其已交付历史和验证，不把本次确认写成已部署。

范围/预期：仅对已启用的显式映射，短时未知保留；目标长期未知、其他实际可参与分流的受管线路有新鲜且匹配当前绑定的成功证据时排除目标。全体未知保留本轮决策前的实际资格、提示并继续检查，不借此重新加入已排除/冷启动/绑定失效成员。明确未认证/物理故障仍按原逻辑剔除；新成功证据才允许恢复。

非目标：不承诺全体未知时硬性 TTL 或零黑洞，不新增独立高频探测、万能检测站自动切换或认证请求，不修改账号/网口/mwan3 权重/策略/原生跟踪，不扩展 IPv6/其他后端，不做灯号仪表盘，不包含真实部署/推送/公开发布。

依赖：现有映射/绑定/原生 apply 与已完成检查证据；[CL-SCHED-01](scheduled-outage-retry.md)的主动降频/时间状态和 [CL-CORE-01](concurrency-account-fuse.md)的账号级门禁语义须在联调前明确，以区分调度停止和故障。Doctor 不作为独立认证许可或绕过正式证据的来源。各环境策略是否由剩余成员承接需实际验证，原设备物理 WAN 兜底不能推广到所有开源用户。

关键规则与工程承接：

- 分开最后成功与最近检查；失败、重复读取旧 online 和旧任务结果不能刷新成功年龄。现有 last_check 同时用于失败，不能直接充当成功时间。
- 以同一轮全局快照计算健康证据和资格变化，控制遍历/执行顺序，避免全体误剔除。健康比较对象必须属于适用受管集合、匹配当前绑定，并实际可参与分流；未映射/停用对象不被接管。
- 全体未知分支保留当前状态，不恢复已退出成员，不覆盖明确未认证或物理故障。源服务失联或桥接服务重启不能把旧快照当新成功；桥接停止期间本组件无法主动执行过期，边界需披露。
- 主动停网等待、降低检查频率、账号暂停和停止认证调度本身不证明断网；宽限和证据新鲜度按检查/退避/降频相容关系确定并验证，不机械采用 5–10 分钟，也不新增所有内部设置项。
- 既有原生 disconnected 可能清理成员连接；状态解释暂停原因和最后成功时间，不能把保留资格写成刚验证健康。保护认证出口及管理路径，逐路绑定/配置/物理事件校验保留。

路线/规模/风险：产品变更、短任务；当前只有契约记录，具体实现风险待定。成功年龄/全局集合判断错误可能导致多路误剔除和连接中断，需可控时钟、多路同时未知、遍历顺序、保护路径及实际剩余策略验证；实现后若仍无法排除广泛故障按 R2 补独立审查，不因规则代码少或沿用原 apply 自动定 R1。

验证计划：可控时间/状态序列验证短时未知、单路长期未知、全体同时未知、部分已有离线、旧快照重复、成功/失败时间、时钟校正、绑定/配置/物理变化和新证据恢复；重启/失联/停网降频/账号暂停不误判或解锁。对同一快照交换遍历顺序验证一致性；验证仅剩健康成员承接实际新连接、旧连接影响与原认证/管理路径。测试有限次数、有超时，不主动断开全部真实线路或制造学校账号异常。

状态：需求已确认、实施未开始；行为验证、风险定级及按最终影响所需审查待补；未打包、部署或发布。下一步在实现承接时确定宽限/新鲜度初值与所需调度状态字段，不再就已确认的默认策略重复访谈。

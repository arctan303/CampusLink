# CampusLink v0.4.2 试用版：深澜变体与锐捷 RSA

新增实验性深澜 SRBX1 和锐捷 ePortal 适配，基于公开学校工具的协议分析独立实现，等待对应校园使用者反馈。

- 深澜：两种 HMAC、error/res 状态、受限同源 AC ID 自动发现；也可继续手填 AC ID。
- 锐捷：保留非 RSA，新增明确选择的 RSA 零填充模式，同源 pageInfo 公钥及一次/双重表单编码；仅支持免验证码、ASCII 单块与 1024/2048 位公钥。
- 未知页面、跨源目标、重复/IP 不匹配参数或无效公钥不发送密码；不自动降级。认证被接受后仍需联网复查。
- Dr.COM 与 schema 2 配置保持兼容，路由器不需要 Python 或 Node。

安装包：`campuslink_0.4.0-1_all.ipk` + `luci-app-campuslink_0.4.2-1_all.ipk`；可选 `campuslink-mwan3_0.2.0-1_all.ipk`。另附干净源码 ZIP 和 SHA256SUMS。[安装与回退](../Install.md) · [配置、参考源码和反馈](../providers/experimental.md)。

离线验证覆盖独立加密向量、实际 ucode worker、curl 回环编码和 LuCI 回归。新协议尚未在真实校园、目标固件原生或多 WAN 环境测试；原生 RSA 性能、进程取消仍待反馈。请先单路手动验证，再启用自动登录；不支持验证码、CAS/Cookie、运营商第二密码或其它同厂商协议。

反馈请提供学校/系统、插件/固件版本、模式及已脱敏原因码；不要上传密码、Cookie、密文、挑战、完整 queryString、配置或 HAR。v0.4.1 保持稳定版。

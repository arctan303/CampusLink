# CampusLink v0.4.1

OpenWrt 校园网自动登录插件，当前适配 Dr.COM HTTP 门户。

## 本次更新

- 移除学校选择，统一通过“登录系统”和认证服务器配置；兼容旧配置的有效参数。
- 独立“mwan3 联动”设置标签：选择参与接口、映射已有 mwan3 接口、查看关联成员及实际状态，最多 32 条映射。
- 总览支持手动查询各 WAN 的公网 IPv4，显示查询时间、冷却、过期和失败状态。
- 更新中文安装、升级及常见问题说明。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `campuslink_0.3.0-1_all.ipk` | 必装：登录后台 |
| `luci-app-campuslink_0.4.1-1_all.ipk` | 必装：LuCI 界面 |
| `campuslink-mwan3_0.2.0-1_all.ipk` | 可选：mwan3 联动 |
| `CampusLink-0.4.1-source.zip` | 插件源码、文档与测试，不含历史登录脚本 |
| `SHA256SUMS` | 上述下载文件的校验值 |

组件版本独立，按表搭配即可。将前两个 IPK 上传到路由器 `/tmp/` 后执行：

```sh
opkg install /tmp/campuslink_0.3.0-1_all.ipk /tmp/luci-app-campuslink_0.4.1-1_all.ipk
```

重新登录 LuCI，打开“服务 → CampusLink”，填写服务器、账号和线路，先手动检查，再开启自动登录。可选组件的前置配置与安装步骤见[安装说明](https://github.com/arctan303/CampusLink/blob/v0.4.1/docs/Install.md)和[联动说明](https://github.com/arctan303/CampusLink/blob/v0.4.1/packages/campuslink-mwan3/README.md)。

## 已验证范围与限制

已在 OPKG 的 Kwrt 25.12-SNAPSHOT 上验证安装、原生 RPC、四 WAN 公网 IP 查询和三路排除/四路恢复。IPK 可复现构建，并与设备已验证载荷比对；验证记录见 [0.4.0](https://github.com/arctan303/CampusLink/blob/v0.4.1/docs/testing/0.4.0.md)及 [0.4.1](https://github.com/arctan303/CampusLink/blob/v0.4.1/docs/testing/0.4.1.md)。

- 需要 ucode 与支持 `ifhost!设备!IP` 的 curl 8.9+；APK 固件尚未验证。
- 联动仅验证 mwan3-nft 3.6.12-r4 / IPv4；不创建网络、成员或策略。持续未知仍保留上次资格，停止联动保留当前成员状态。
- 公网 IP 查询只代表到 IPIP 服务的直连出口，代理或游戏加速器可能不同。
- 游戏电脑固定 WAN、并发上限 4、账号级熔断、计划停网重试和一键诊断报告尚未实现。
